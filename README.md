# Sumit Singh — Software Engineer Portfolio

Cinematic portfolio of Sumit Singh, Software Engineer specializing in backend systems, APIs, AI-powered products, and modern web applications.

## Technologies

- **Framework**: TanStack Start, React 19, TypeScript
- **Styling**: Tailwind CSS v4, Motion (Framer Motion)
- **Backend & APIs**: Python, FastAPI, Node.js, Spring Boot
- **Data & AI**: PostgreSQL, MongoDB, Redis, Vector Databases, LLM & RAG Pipelines
